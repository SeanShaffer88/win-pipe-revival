# Support for this revival

Use [this fork's Issues](https://github.com/SeanShaffer88/win-pipe-revival/issues) for its releases, build failures and maintenance questions. Include a release/tag or commit, Windows build, architecture, compiler and a minimal synthetic reproduction. This is an independent continuation; do not assume upstream maintains these changes. Historical license and attribution remain in place.

Use the [security policy](SECURITY.md) for sensitive reports. Check the README's current milestone and limitations before relying on a feature. Help is best-effort; no support SLA is promised.
